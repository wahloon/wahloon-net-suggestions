# wahloon.net suggestions

This is the public issue tracker for [wahloon.net](https://www.wahloon.net). The site source and CMS are maintained in a private repository; this repository exists so model suggestions and corrections stay public.

Use an issue form:

- **Suggest a model** — propose an abliterated or uncensored open-weight model for the catalog.
- **Suggest a guide** — propose a practical local-setup or hardware topic.
- **Report a correction** — flag a stale number, wrong license, broken link or typo.

Please link the original Hugging Face repository or the page you are correcting, and keep claims verifiable. Suggestions are reviewed before anything is published.
